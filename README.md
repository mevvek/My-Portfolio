# Vivek Yadav — Developer Portfolio

A minimal, high-performance developer portfolio built with React, Vite, Tailwind CSS, and Framer Motion. Engineered with a dark editorial developer aesthetic, responsive typography, offset scroll-spy routing, and client-side document delivery.

🔗 **Live Demo:** [https://my-portfolio-weld-nu-51.vercel.app/](https://my-portfolio-weld-nu-51.vercel.app/)

---

## ⚡ Key Highlights & Architecture

- **Dark Editorial Aesthetic:** Clean, typography-driven UI designed for engineering clarity without unnecessary visual noise or heavy 3D assets.
- **Dynamic Scroll-Spy Engine:** Custom offset navigation syncing the URL hash (`#about`, `#projects`, `#tech-stack`, `#experience`, `#education`, `#certificates`, `#contact`) smoothly with active viewport thresholds.
- **Client-Side Document Archive:** Integrated credential registry supporting direct PDF rendering for verified certifications, offer letters, and job simulations.
- **Optimized Asset Pipeline:** Bundled with Vite for instant HMR in development and lightweight production builds (~126 kB gzip JS).

---

## 🛠 Tech Stack

- **Core Framework:** React 19, Vite
- **Styling:** Tailwind CSS, PostCSS
- **Animations:** Framer Motion
- **Icons & Tooling:** Lucide React, ESLint
- **Deployment:** Vercel (Edge Network)
